## Comparison with the paper

The RCAEval paper reports no RE2-OB numbers; its Table 6 covers RE2-TT. The
reproduction target is therefore RCAEval's own `main.py` on RE2-OB at a pinned
commit. Our scorer (`eval/rcaeval/scoring.py`) reproduces the Avg@5 that
`main.py` prints for every method and fault type with a difference of 0.00
(checked in `n1_report.py`, stored as `avg5_parity_vs_main_py`).

## Why our earlier BARO said 0.30 (the redis hypothesis)

The roadmap's hypothesis was that our preprocessing crippled BARO and made it
blame redis. `eval/rcaeval/redis_hypothesis.py` tests this by changing one thing
at a time, from our original harness to the official pipeline:

| Variant | AC@1 | redis ranked first (of 90) |
|---|---:|---:|
| A0: original harness (drop constant columns, `baro(data, inject_time)`) | 0.30 | 59 |
| A: plus RCAEval's `dataset="re2-ob"` argument | 0.18 | 71 |
| B: A plus inf→NaN, forward fill, fill 0 | 0.14 | 77 |
| C: A plus a ±10-minute window | 0.17 | 72 |
| D: exact `main.py` preprocessing | 0.14 | 77 |
| E: archived official `main.py` run | 0.14 | 77 |
| F: D with metrics whose normal-period IQR is 0 dropped (diagnostic) | 0.81 | 1 |

Conclusions:

1. **The hypothesis is rejected.** Redis dominance is stronger in the official
   pipeline (77/90) than in ours (59/90). No RE2-OB fault targets redis, so
   every redis top-1 is wrong.
2. **The old 0.30 is an artifact of calling `baro()` without `dataset`.** With
   `dataset` set, RCAEval drops time and constant columns per period and
   converts memory to MB. Without it, those steps are skipped. Official BARO on
   RE2-OB is AC@1 0.14 (Avg@5 0.74), and our fixed harness reproduces that
   exactly (variant D = E).
3. **Root cause of the redis dominance:** in 77 cases the top metric is
   `redis_diskio`. It is 0 for most of the normal period, so its IQR is 0, and
   scikit-learn's `RobustScaler` silently uses a scale of 1. Any write burst
   after the injection then scores z ≈ 10⁴ and outranks real symptoms. Dropping
   zero-IQR metrics (variant F) lifts BARO to AC@1 0.81. This is a property of
   BARO on this data, not of our pipeline. We report F only as a diagnostic and
   a fairer bar for Phase 1, not as "BARO".

## Preprocessing: our harness vs `main.py`

`eval/rcaeval/baselines.py::_prepare_metrics` now mirrors `main.py`: drop
duplicate columns, sort by time, drop `*_latency-50`, inf→NaN, forward fill,
fill 0, keep 600 rows (10 minutes at 1 s) on each side of the injection, and
rename `*_latency-90` → `*_latency`. The harness now passes `dataset`.
The original harness only dropped constant columns, used the full case, and
passed no `dataset`. `tests/test_baseline_preprocessing.py` pins this
behaviour. Re-run harness results: BARO AC@1 0.14, N-Sigma 0.79, E-Diagnosis
0.03, all matching the official runs.

Codex's earlier "project BARO 0.744" came from feeding the raw `metrics.csv`
(not the benchmark's `simple_metrics.csv` input) through a harness whose case
ids were not unique. It is not comparable to any published number and is
withdrawn.

## Provenance and reproduction

- RCAEval checkout `../external/RCAEval`, unmodified. The commit, dataset md5
  (Zenodo RE2-OB, `b9e23f88…`), Python versions and commands are in
  `eval/artifacts/rcaeval/official_runs/provenance.json` and
  `official_runs/<method>/run.json`, next to stdout, stderr and the per-case
  rankings.
- Default env: Python 3.12, `pip install -e ".[default]"`.
- RCD env: Python 3.8, `pip install -e ".[rcd]"` with numpy 1.23.5
  preinstalled, `pyyaml==6.0.1`, tigramite built without build isolation, then
  upstream's `script/link.sh`. That script symlinks RCAEval's patched
  `causallearn` files, which provide `local_skeleton_discovery`. The earlier
  "RCD incompatible" result came from skipping this step.
- CIRCA runs unmodified through `main.py`. The earlier "method not registered"
  was an environment issue.
- PDiagnose is not wired into upstream `main.py`. `scripts/run_pdiagnose.py`
  ports upstream's `pdiagnose.py` (3-sigma metric votes, "error|fail" log
  votes, per-operation trace 3-sigma, α = 5).

```bash
make rcaeval-official   # all methods → eval/artifacts/rcaeval/official_runs/
make n1-report          # redis hypothesis + tables → eval/artifacts/rcaeval/n1/
```
